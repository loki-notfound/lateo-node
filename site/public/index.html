A public Zephyr node

node.lateo.dev is a free remote node for Zephyr wallets. Point your wallet at it and it syncs without downloading the blockchain yourself.

Use it

Desktop wallet

In the wallet's settings, under Nodes: click Disconnect, select Custom Node, fill in the two fields and click Connect.

Node Addresshttps://node.lateo.dev
Node Port443

Type the https://; without it the wallet does not connect.

Command-line wallet

zephyr-wallet-cli --daemon-address node.lateo.dev:443

If the wallet warns that it has not verified the node's certificate, give it the system's certificate list. On Debian and Ubuntu:

SSL_CERT_FILE=/etc/ssl/certs/ca-certificates.crt \
  zephyr-wallet-cli --daemon-address node.lateo.dev:443

Do not add --daemon-ssl enabled; the wallet does not start with it.

Check that it answers

curl https://node.lateo.dev/get_info

What it is

  • Several machines, one address. The node runs on more than one host in different places. Cloudflare sends each request to a host that is up; when one goes down, the others keep answering.
  • Restricted RPC. Wallets can read the chain and submit transactions. Mining, peer and administrative calls are switched off.
  • The daemon. Every host runs a myzephyr release, a build of Zephyr v2.3.0 with security fixes ported from Monero. It speaks the same protocol as the official release.
A remote node is a trust trade-off. It never sees your keys or your balance, but its operator and Cloudflare, which carries the traffic, can see your IP address and when your wallet syncs or sends. For full privacy, run your own node.

Run your own

A single node

One Docker container on one machine. No Cloudflare account, no domain. Your wallet talks to your own node.
