Run your own Zephyr node

One machine, one Docker container. Your wallet talks to your own node, and the network gains a peer. No Cloudflare account needed.

What it needs

  • Docker on linux/amd64 or linux/arm64; see Docker's install guide.
  • Disk: the database was about 25 GiB in November 2026 and grows with the chain. An SSD makes the first sync much faster.
  • Time: a sync from scratch took about 11.5 hours on one test machine in November 2026; expect anything from hours to days.
  • Network: an ordinary internet connection. Forwarding port 17766 to the machine is optional and helps the network.

1. Choose an image

myzephyrzephyr
Binarya personal build of v2.3.0 with security fixesthe official v2.3.0 release, unchanged
Verified bya signed list of hashes, checked during the buildhashes recorded when the image was made; upstream publishes none
Security fixes30 fixes ported from Moneronone beyond v2.3.0
Finding peersworks out of the boxworks with the seed list the image sets; the seeds built into v2.3.0 no longer answer

Take zephyr to run exactly what ZephyrProtocol shipped, and myzephyr for the security fixes, from a single maintainer. The data works with either image, so you can switch later. The commands below use myzephyr; for the other, write ghcr.io/loki-notfound/zephyr:latest.

2. Start it

docker run -d --name zephyrd --restart unless-stopped \
  --stop-timeout 300 \
  -p 17766:17766 -p 17767:17767 \
  -v zephyrd-data:/data \
  ghcr.io/loki-notfound/myzephyr:latest
-p 17767:17767 offers the node's RPC, restricted to reading the chain and sending transactions, on every address of the machine, so wallets on your network can use it. On a machine with a public address, such as a rented server, that is anyone, and a firewall like ufw does not stop it: Docker publishes ports past it. For this machine only, write -p 127.0.0.1:17767:17767 instead.

3. Watch it sync

docker logs -f --tail 20 zephyrd

The log counts up as Synced <height>/<target>; leave it with Ctrl-C, the node keeps running. Or ask the node:

curl -s http://127.0.0.1:17767/get_info | grep -E '"(height|target_height|synchronized)"'

It is ready when synchronized is true.

4. Connect your wallet

zephyr-wallet-cli --daemon-address 127.0.0.1:17767

In the desktop wallet, under Nodes in the settings, select Custom Node with address 127.0.0.1 and port 17767. From another computer on your network, use the address of the node's machine instead of 127.0.0.1.

5. Keep it up to date

docker pull ghcr.io/loki-notfound/myzephyr:latest
docker stop zephyrd
docker rm zephyrd

Then repeat the command of step 2. The chain data stays in the volume zephyrd-data, so the node continues where it stopped.

Settings

Settings are environment variables: add -e NAME=value to the command of step 2, before the image name. For example, -e PRUNE=true keeps roughly a third of the chain data. The full list is in the repository. Never set RESTRICTED_RPC=false on a node whose port 17767 others can reach.

More

  • With Docker Compose instead of docker run, and more on peers and updates: the standalone guide.
  • To serve others without an open port: a Cloudflare Tunnel, as described under high availability; one host is enough for that.
  • Without these images: myzephyr releases (the binaries of the myzephyr image, with a signed hash list), ZephyrProtocol releases (the official binaries), or jnitecki/zephyr, a third-party image of v2.3.0 whose source and binary origin are not published.
